# ============================================================
#  候选池：会从这些"公共聚合配置"里自动抽取可直连的 CMS 站点
# ============================================================
#  构建时脚本会抓取下面每个 URL，解析其中的 sites 数组，
#  只取 type=1（JSON CMS 直连，不需要 spider.jar）的站点，
#  统一验证后再汇总进你自己的源。
#
#  这也正是"源会自愈"的原因：别人的单源挂了，但他们的配置里
#  往往同时挂着几十个 CMS 站，我们把其中还活着的捞出来。
#
#  格式：  分组名 | URL | URL | ...
#  一个分组可以有多个镜像地址，脚本会全部尝试，取第一个成功的。
#  整行以 # 开头即注释。
# ============================================================
